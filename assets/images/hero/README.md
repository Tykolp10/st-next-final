# 📁 HERO IMAGES FOLDER

Upload foto untuk section HERO (banner utama halaman) di sini.

## Panduan Upload:
- **Format**: JPG, PNG, atau WebP
- **Ukuran ideal**: 1920 x 1080 px (landscape/widescreen)
- **Ukuran file**: Maksimal 2MB per gambar
- **Penamaan file**: `hero-1.jpg`, `hero-2.jpg`, `hero-3.jpg`, dst.

## Jumlah Foto:
- Minimal 1 foto, maksimal 5 foto (untuk slider/carousel)

## Contoh Konten:
- Foto lifestyle / suasana santai
- Foto alam/nature yang tenang dan damai
- Foto momen sosial yang hangat
