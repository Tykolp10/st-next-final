# 📁 PRODUCTS IMAGES FOLDER

Upload foto produk ST (Sehat Tentrem) di sini.

## Panduan Upload:
- **Format**: JPG, PNG, atau WebP (PNG disarankan untuk background transparan)
- **Ukuran ideal**: 600 x 800 px (portrait)
- **Ukuran file**: Maksimal 1MB per gambar
- **Penamaan file**: `st-classic.jpg`, `st-kretek.jpg`, `st-mild.jpg`, dst.

## Konten yang Diperlukan:
- Foto kemasan produk (tampak depan)
- Foto produk dari berbagai sudut (opsional)
- Background polos atau transparan lebih baik
