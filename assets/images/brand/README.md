# 📁 BRAND IMAGES FOLDER

Upload aset visual brand ST (Sehat Tentrem) di sini.

## File yang Diperlukan:
- **Logo Utama**: `logo-st.png` (transparent background, PNG)
  - Ukuran: min 500 x 200 px
- **Logo Putih**: `logo-st-white.png` (untuk background gelap)
- **Favicon**: `favicon.ico` atau `favicon.png` (32x32 px)
- **About Section Image**: `about-st.jpg` (1200 x 800 px)
  - Foto pabrik, sejarah brand, atau founders

## Format Logo:
- Gunakan PNG dengan background transparan
- Resolusi tinggi (min 300 DPI untuk print quality)
